# OctoAcme — Persona Engagement Checklist

## Purpose
Use this checklist during planning, implementation, release, post-release, and incident response to confirm the right personas are involved at the right time.

## How to Use
- Mark each item as **Required**, **Optional**, or **Not Needed**
- Assign an owner for each required engagement
- Record links to artifacts (plans, dashboards, incident notes, release notes)

## 1) Planning
- [ ] Technical Lead engaged for architecture and technical risk decisions
- [ ] UX Researcher engaged for user journey or usability assumptions
- [ ] Data Analyst engaged to define success metrics and instrumentation plan
- [ ] Security Reviewer engaged for threat modeling and security constraints
- [ ] Stakeholder Liaison engaged to map communication needs and dependencies

## 2) Implementation
- [ ] Technical Lead reviewing major technical trade-offs
- [ ] UX Researcher validating usability checkpoints (as needed)
- [ ] Data Analyst verifying event tracking and data quality requirements
- [ ] Security Reviewer reviewing high-risk features before code freeze
- [ ] Stakeholder Liaison providing status updates to external groups

## 3) Release
- [ ] Release Engineer owns release readiness and deployment checklist execution
- [ ] Technical Lead confirms technical risk acceptance and fallback options
- [ ] Security Reviewer confirms security readiness for production release
- [ ] Stakeholder Liaison coordinates launch communication and support alignment
- [ ] PM confirms go/no-go decision and escalation path

## 4) Post-release
- [ ] Data Analyst validates outcome metrics and adoption trends
- [ ] UX Researcher gathers user feedback for pain points and opportunities
- [ ] PM and PdM review results and convert findings into backlog actions
- [ ] Stakeholder Liaison shares outcome summary with stakeholders

## 5) Incident Response
- [ ] PM coordinates communications cadence and escalation log
- [ ] Technical Lead drives technical triage and remediation plan
- [ ] Release Engineer executes rollback or deployment mitigation steps
- [ ] Security Reviewer leads containment guidance if security risk is involved
- [ ] Stakeholder Liaison provides structured updates to affected stakeholders
